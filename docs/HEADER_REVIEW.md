# NetSpecter Header/Toolbar Review #

The Header toolbar area that exposes all of the options of NetSpecter has become muddled and chaotic.

We have Network and Web workspaces below the main toolbar. Yet the web workspace has virtually no options in the header toolbar that apply to it.

We should perform a functional user interface review to reorganize all of the options to have a more focused, clearly delineated user interface based off of the area the user is in.

Current Header options:

- Logo: applies to all
- Add Hosts: Only applies to network space
- Blacklist: only applies to network space
- Save: applies to all?
- Load: applies to all?
- Clear: only applies to hosts on network space?
- Settings: Applies all the time
- RevShell: network space only
- Cred Spray: network space only
- Shares: network space only
- Dir Fuzz: network space only
- Monitor: network space only
- Cloud Enum: network space only
- VLAN Discovery: network space only
- Passive Intelligence: network space only
- Host View radio options: network space only
- Filtering inputs: network space only
- Exit: applies to all

Depending on if the user is in the network or web workspace, they should only see the options that apply

Take a thorough look at how we have presented all of the options and take into consideration that future additional features will be added to both types of spaces in considering the UI redesign for the header
