# Netspectre Header/Toolbar Review #

The Header toolbar area that exposes all of the options of NetSpectre has become muddled and chaotic.

We have a Network and Web "workspace" and that is below the main toolbar.  Yet the web workspace has virtually no options in the header toolbar the apply to it.

We should perform a functional user inteface review to reorganize all of the options to have a more focused, clearly delinated user interface based off of the area the user is in.

Current Header options:

- Logo: applies to all
- Add Hosts: Only applies to network space
- Blacklist: only applies to network space
- Save: applies to all?
- Load: applies to all?
- Clear: only applies to hosts on network space?
- Settings: Applies all the time
- RevShell: network space only
- Cred Spray: network space only
- Shares: network space only
- Dir Fuzz: network space only
- Monitor: network space only
- Cloud Enum: network space only
- VLAN Discovery: network space only
- Passive Intelligence: network space only
- Host View radion options: network space only
- Filtering inputs: network space only
- Exit: applies to all

Depending on if the user is in the network or web workspace, they should only see the options that apply

Take a thorough look at how we have presentecd all of the options and take into consideration future additional features will be added to both types of spaces in considerating the UI redesign for the header
